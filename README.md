# Diamonds Data Analysis

Short analysis and plotting utilities for the diamonds dataset.

## Project files
- `analyze_diamonds.py` — script to analyze `diamonds.csv` and produce plots.
- `diamonds.csv` — input dataset.
- `plots/` — output directory for generated plots.

## Prerequisites
- Python 3.8+
- Install dependencies:

```
pip install pandas matplotlib seaborn
```

## Usage
Run the analysis script from the project root:

```
python analyze_diamonds.py
```

Generated plots will be saved to the `plots/` directory.
